# Замерятель скорости интернета

Скрипт делает 10 последовательных запросов к адресу тяжёлого файла (по умолчанию —
картинка ~7.6 МБ с Unsplash), каждый раз скачивает ответ целиком и печатает:

- время каждого запроса;
- среднее время запроса;
- объём скачанных данных;
- скорость в Мбит/с (и в МБ/с).

Скорость = весь скачанный объём / суммарное время всех запросов.

Внешних зависимостей нет — только стандартная библиотека Python 3.8+.

## Запуск

```bash
git clone <адрес репозитория>
cd internet-speed-test

python speedmeter.py                      # картинка по умолчанию
python speedmeter.py https://example.com/big-image.jpg   # свой адрес
```

Через pipenv:

```bash
pipenv install
pipenv run python speedmeter.py
```

## Пример вывода

```
Адрес: https://images.unsplash.com/photo-1506744038136-46273834b3fb?fm=jpg&q=100
Запрос  1: 0.589 с, 7.62 МБ
Запрос  2: 0.502 с, 7.62 МБ
...
Запрос 10: 0.518 с, 7.62 МБ
Среднее время запроса: 0.529 с
Скачано всего: 76.17 МБ (76166480 байт)
Скорость: 115.21 Мбит/с (14.40 МБ/с)
```
