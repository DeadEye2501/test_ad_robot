# Замерятель скорости интернета

Скрипт делает 10 последовательных запросов. Каждый запрос — это параллельное скачивание
набора тяжёлых картинок (по умолчанию 10 штук по 4–20 МБ с трёх хостов: Unsplash,
ESA Webb, ESA Hubble). Запрос считается завершённым, когда докачалась последняя картинка.

Скрипт печатает:

- время, объём и скорость каждого запроса;
- среднее время запроса;
- объём скачанных данных;
- скорость в Мбит/с (и в МБ/с) — весь скачанный объём / суммарное время запросов.

Зачем параллельно: одно соединение до одного хоста упирается в этот хост и почти
никогда не выбирает весь канал. Speedtest тоже качает в несколько потоков — и с
набором по умолчанию цифры скрипта близки к его результату.

Один прогон с адресами по умолчанию скачивает около 1.25 ГБ.

Внешних зависимостей нет — только стандартная библиотека Python 3.8+.

## Запуск

```bash
git clone https://github.com/DeadEye2501/test_ad_robot.git
cd test_ad_robot

python speedmeter.py                                   # набор картинок по умолчанию
python speedmeter.py https://example.com/big.jpg       # один свой адрес
python speedmeter.py https://a.com/1.jpg https://b.com/2.jpg   # свой набор, качается параллельно
```

Через pipenv:

```bash
pipenv install
pipenv run python speedmeter.py
```

Если запрос не удался (сеть, ошибка HTTP, таймаут 30 с), скрипт печатает номер запроса
и причину и выходит с кодом 1.

## Пример вывода

```
Адресов: 10, в каждом запросе качаются параллельно
Запрос  1: 5.335 с, 125.38 МБ, 188.00 Мбит/с
Запрос  2: 5.016 с, 125.38 МБ, 199.95 Мбит/с
...
Запрос 10: 5.033 с, 125.38 МБ, 199.28 Мбит/с
Среднее время запроса: 5.088 с
Скачано всего: 1253.75 МБ (1253753300 байт)
Скорость: 197.13 Мбит/с (24.64 МБ/с)
```

Для сравнения: `speedtest-cli` на том же подключении показал 187.52 Мбит/с.

## Тесты

